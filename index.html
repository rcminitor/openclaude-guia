Guia de Configuração • Windows

OpenClaude & OpenRouter

Instalação descomplicada, atualização de ambiente com Node 22+ e conexão direta com modelos gratuitos.

01

Verificar e Atualizar o Node.js

O OpenClaude requer Node.js 22 LTS ou superior. Abra o PowerShell e consulte o seu ambiente:

PowerShell 
node -v
npm -v

Caso o comando não seja reconhecido ou seja inferior à versão v22.x, instale pelo winget:

PowerShell 
winget install OpenJS.NodeJS.LTS
Importante: Após a conclusão pelo winget, feche o PowerShell e abra uma nova janela para recarregar o sistema.
02

Instalar o OpenClaude CLI

Com o Node 22+ ativo, instale globalmente o binário:

PowerShell 
npm install -g @gitlawb/openclaude@latest

Se o comando openclaude não for reconhecido, execute para corrigir o PATH:

PowerShell 
$npmPrefix = npm config get prefix
$currentUserPath = [Environment]::GetEnvironmentVariable("Path", "User")
if (($currentUserPath -split ';') -notcontains $npmPrefix) {
    [Environment]::SetEnvironmentVariable("Path", "$currentUserPath;$npmPrefix", "User")
}
03

Obter Chave e Modelo no OpenRouter

  1. Acesse o portal oficial em openrouter.ai e conecte sua conta.
  2. No menu Keys, gere uma chave com Create Key e copie o token gerado (sk-or-v1-...).
  3. No catálogo de Models, utilize o roteador genérico gratuito openrouter/free ou modelos com a etiqueta :free.
04

Executar com o Modelo Gratuito

Cole no PowerShell substituindo pela sua chave para iniciar imediatamente sem custos:

PowerShell 
$env:CLAUDE_CODE_USE_OPENAI="1"
$env:OPENAI_BASE_URL="https://openrouter.ai/api/v1"
$env:OPENAI_API_KEY="sk-or-sua-chave-aqui"
$env:OPENAI_MODEL="openrouter/free"
