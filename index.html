O que é o OpenClaude?

O OpenClaude (mantido pela organização Gitlawb) é um fork de código aberto do Claude Code que liberta você do ecossistema fechado de uma única provedora. Ele transforma seu terminal em uma central de desenvolvimento autônomo com agentes inteligentes.

🌐 Independência de Provedor

Conecte-se a mais de 200 modelos via OpenRouter, use Ollama local 100% offline e grátis, DeepSeek, Groq ou Gemini.

⚡ Agente Autônomo Completo

Ele não apenas responde perguntas: ele cria arquivos, edita código cirurgicamente, roda testes, executa comandos bash/PowerShell e faz buscas com ripgrep.

🔌 Protocolo MCP

Integração nativa com Model Context Protocol, permitindo que a IA consulte bancos de dados, APIs do GitHub, documentações externas e ferramentas personalizadas.

Tutorial com prints

Do zero ao primeiro prompt, tela por tela

Roteiro real de uma instalação no Windows: reinstalar o OpenClaude, conferir o ambiente e passar pelo assistente de configuração usando o OpenRouter com modelos gratuitos.

▶

Vídeo de referência

Este tutorial segue o vídeo "Claude Code GRÁTIS?? Como Instalar o OpenClaude no Windows + VSCode!", do canal GXDEV. O vídeo começa no trecho da instalação (2:59).

Não carregou? Assista direto no YouTube.

T1

Remover uma instalação antiga (opcional)

Se o OpenClaude já estava instalado e você quer começar limpo, remova só o pacote dele. A configuração antiga fica na pasta .openclaude e no arquivo .openclaude.json do seu usuário.

PowerShell 
npm uninstall -g @gitlawb/openclaude

# Opcional: apaga a configuração antiga (inclusive chaves salvas)
Remove-Item -Recurse -Force "$env:USERPROFILE\.openclaude", "$env:USERPROFILE\.openclaude.json"
Não confunda com o Claude Code. O OpenClaude e o Claude Code oficial são programas diferentes. O Claude Code vem do pacote @anthropic-ai/claude-code (ou do instalador nativo em %USERPROFILE%\.local\bin\claude.exe) e guarda a configuração em .claude\. Nada disso precisa ser removido para reinstalar o OpenClaude.
T2

Conferir Node.js, npm e Git

Rode cada comando. Se aparecer um número de versão, está instalado; se aparecer "não é reconhecido como comando", não está. O npm vem junto com o Node.

PowerShell ou CMD 
node -v
npm -v
git --version

Não tem o Node? Escolha um dos caminhos:

  • winget (mais simples, já vem no Windows 10/11): winget install OpenJS.NodeJS.LTS
  • Site oficial: baixe a versão LTS em nodejs.org e mantenha marcada a opção "Add to PATH".
  • Chocolatey (o caminho do vídeo de referência): exige o terminal como administrador.
Erro "requires Administrative permissions" no Chocolatey? O terminal não estava aberto como administrador. Menu Iniciar → digite cmd → botão direito em Prompt de Comando → Executar como administrador. Se o Node já estiver instalado, pule o Chocolatey: ele só serve para instalar o Node.
PowerShell não é CMD. Comandos como [Environment]::SetEnvironmentVariable(...) só funcionam no PowerShell. No CMD eles dão "A sintaxe do nome do arquivo... está incorreta".
T3

Instalar o OpenClaude

PowerShell ou CMD 
npm install -g @gitlawb/openclaude@latest
openclaude --version
Deu certo quando aparecer added 8 packages na instalação e algo como 0.31.0 (OpenClaude) na versão.
T4

Abrir dentro da pasta do projeto

O OpenClaude trabalha na pasta em que foi aberto: ele pode ler, editar e executar arquivos ali. Por isso, entre na pasta do projeto antes de abri-lo.

PowerShell 
# Crie uma pasta de testes (ou use a do seu projeto)
mkdir $env:USERPROFILE\Projetos\teste-openclaude
cd $env:USERPROFILE\Projetos\teste-openclaude
openclaude
T5

Assistente de configuração, tela por tela

Na primeira execução, o OpenClaude abre um assistente. São sete telas:

API key: crie a sua em openrouter.ai/keys (começa com sk-or-v1-). Cole só no terminal do OpenClaude: nunca em chats, prints, repositórios ou arquivos que vão para o GitHub.
Sair nessa tela não perde nada: a configuração do OpenRouter já ficou salva. Ao abrir de novo, o assistente vai direto para a confirmação da pasta.
T6

Passo 01

Pré-requisitos no Windows

Certifique-se de ter as ferramentas de sistema recomendadas instaladas antes de iniciar o OpenClaude.

01

Verificar e Atualizar o Node.js

O OpenClaude requer Node.js 22 LTS ou superior para funcionar com total suporte às APIs mais recentes. Abra o PowerShell e consulte o seu ambiente:

PowerShell 
node -v
npm -v

Caso o comando não seja reconhecido ou a versão seja inferior à v22.x, instale diretamente pelo winget oficial da Microsoft:

PowerShell 
winget install OpenJS.NodeJS.LTS
Atenção: Após a conclusão pelo winget, feche o terminal do PowerShell e abra uma nova janela para que o Windows recarregue as variáveis de ambiente do Node.
02

Instalar Git e Ripgrep (Recomendado)

O OpenClaude utiliza o Git para rastrear alterações e gerar commits, e o Ripgrep (rg) para localizar trechos de código em milissegundos dentro do seu projeto:

PowerShell (Instalação via Winget) 
# Instalação do Git for Windows
winget install Git.Git

# Instalação do Ripgrep para buscas rápidas
winget install BurntSushi.ripgrep.MSVC

Também certifique-se de que a política de execução de scripts do PowerShell permita carregar binários locais:

PowerShell (Executar como Usuário) 
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned -Force
Passo 02

Instalação Global do OpenClaude CLI

Instale o pacote oficial via npm para torná-lo acessível em qualquer pasta do seu computador.

03

Instalar o Pacote npm

Com o Node 22+ ativo, execute a instalação global:

PowerShell 
npm install -g @gitlawb/openclaude@latest

Para confirmar que a instalação ocorreu com êxito, consulte a versão:

PowerShell 
openclaude --version
O comando não foi reconhecido? No Windows, o npm às vezes não inclui a pasta global de binários no PATH do usuário. Caso receba o erro "o termo 'openclaude' não é reconhecido", execute o bloco corretor abaixo:
PowerShell (Correção Automática de PATH) 
$npmPrefix = npm config get prefix
$currentUserPath = [Environment]::GetEnvironmentVariable("Path", "User")
if (($currentUserPath -split ';') -notcontains $npmPrefix) {
    [Environment]::SetEnvironmentVariable("Path", "$currentUserPath;$npmPrefix", "User")
    Write-Host "PATH atualizado com sucesso! Feche e reabra o PowerShell." -ForegroundColor Green
} else {
    Write-Host "O prefixo do npm já está no seu PATH!" -ForegroundColor Cyan
}
Passo 03

Configurar Provedores de IA

Escolha como prefere rodar o OpenClaude: com modelos gratuitos na nuvem, offline na sua máquina ou com os melhores modelos do mundo.

1. Usando com OpenRouter (Gratuito ou Pago)

O OpenRouter é a opção mais flexível, pois dá acesso a centenas de modelos através de uma única API, incluindo modelos com etiqueta :free.

  1. Acesse openrouter.ai e crie ou faça login na sua conta.
  2. No menu lateral Keys, clique em Create Key e copie o token gerado (começa com sk-or-v1-...).
  3. Defina as variáveis no PowerShell e inicie o agente:
PowerShell (OpenRouter Gratuito) 
# Ativar o backend OpenAI compatível
$env:CLAUDE_CODE_USE_OPENAI="1"
$env:OPENAI_BASE_URL="https://openrouter.ai/api/v1"
$env:OPENAI_API_KEY="sk-or-v1-coloque-sua-chave-aqui"

# Para usar o roteador gratuito do OpenRouter:
$env:OPENAI_MODEL="openrouter/free"

# Iniciar o OpenClaude
openclaude
Dica de Modelos Gratuitos: Além de openrouter/free, você pode definir modelos específicos como deepseek/deepseek-r1:free ou meta-llama/llama-3.3-70b-instruct:free. Para modelos pagos de ponta, utilize anthropic/claude-3.5-sonnet ou openai/gpt-4o.

2. Usando com Ollama (100% Local & Privado)

Você pode rodar o OpenClaude totalmente sem internet, usando modelos rodando na sua própria placa de vídeo ou processador com o Ollama.

  1. Instale o Ollama no Windows executando winget install Ollama.Ollama ou baixe em ollama.com.
  2. Abra o terminal e baixe um modelo ideal para programação (como o Qwen 2.5 Coder):
PowerShell (Baixar Modelo Ollama) 
ollama run qwen2.5-coder:14b

Depois, configure o OpenClaude para apontar para o servidor local do Ollama:

PowerShell (Ollama Local) 
$env:CLAUDE_CODE_USE_OPENAI="1"
$env:OPENAI_BASE_URL="http://localhost:11434/v1"
$env:OPENAI_API_KEY="ollama"
$env:OPENAI_MODEL="qwen2.5-coder:14b"

openclaude

3. Usando com DeepSeek Oficial

O DeepSeek oferece um dos melhores raciocínios para código com o custo por token mais baixo do mercado.

  1. Obtenha sua chave em platform.deepseek.com.
  2. Execute os comandos no PowerShell:
PowerShell (DeepSeek) 
$env:CLAUDE_CODE_USE_OPENAI="1"
$env:OPENAI_BASE_URL="https://api.deepseek.com/v1"
$env:OPENAI_API_KEY="sk-sua-chave-deepseek-aqui"
$env:OPENAI_MODEL="deepseek-chat"

openclaude
DeepSeek R1: Se preferir raciocínio profundo passo-a-passo, altere o modelo para $env:OPENAI_MODEL="deepseek-reasoner".

4. Usando com Groq Cloud (Velocidade Extrema)

O Groq é famoso pela latência ultrabaixa e geração de centenas de tokens por segundo em hardware LPU dedicado.

PowerShell (Groq) 
$env:CLAUDE_CODE_USE_OPENAI="1"
$env:OPENAI_BASE_URL="https://api.groq.com/openai/v1"
$env:OPENAI_API_KEY="gsk_sua-chave-groq-aqui"
$env:OPENAI_MODEL="llama-3.3-70b-versatile"

openclaude

5. Assistente Interativo do OpenClaude

Você sabia que não precisa configurar variáveis de ambiente manualmente? O OpenClaude possui um assistente interativo embutido!

  1. Basta abrir o OpenClaude executando: openclaude
  2. Dentro da sessão interativa, digite: /provider
  3. Um menu com opções (OpenRouter, Ollama, OpenAI, Anthropic, Custom) surgirá na sua tela, permitindo salvar perfis permanentes em ~/.openclaude/.
Terminal Interativo OpenClaude 
> /provider
# Siga o menu interativo com as setas do teclado para configurar e trocar de perfil!
Passo 04

Como Deixar as Configurações Permanentes

Evite ter que digitar as chaves e URLs toda vez que fechar e abrir o PowerShell.

📌

Opção A: Salvar no Perfil do PowerShell ($PROFILE)

O arquivo de perfil do PowerShell é carregado automaticamente sempre que uma nova aba ou janela é aberta. Vamos editá-lo:

PowerShell 
# Criar o arquivo de perfil caso ainda não exista
if (!(Test-Path $PROFILE)) { New-Item -Type File -Path $PROFILE -Force }

# Abrir no Bloco de Notas para edição
notepad $PROFILE

Cole as seguintes linhas no final do arquivo que abrir no Bloco de Notas e salve (Ctrl + S):

Conteúdo para o $PROFILE 
# Configuração Padrão do OpenClaude
$env:CLAUDE_CODE_USE_OPENAI = "1"
$env:OPENAI_BASE_URL = "https://openrouter.ai/api/v1"
$env:OPENAI_API_KEY = "sk-or-v1-sua-chave-aqui"
$env:OPENAI_MODEL = "openrouter/free"

# Atalho opcional: basta digitar 'oc' para abrir o openclaude
function oc { openclaude $args }
⚡

Opção B: Criar um Script de Inicialização Rápida (.ps1)

Se você alterna frequentemente entre Ollama, DeepSeek e OpenRouter, crie um script iniciar-openclaude.ps1 na sua pasta de projetos:

iniciar-openclaude.ps1 
$env:CLAUDE_CODE_USE_OPENAI="1"
$env:OPENAI_BASE_URL="https://openrouter.ai/api/v1"
$env:OPENAI_API_KEY="sk-or-v1-sua-chave-aqui"
$env:OPENAI_MODEL="openrouter/free"

Write-Host "Iniciando OpenClaude com OpenRouter..." -ForegroundColor Green
openclaude
Passo 05

Comandos Essenciais do OpenClaude (Slash Commands)

Utilize os comandos internos para controlar sessões, economizar tokens e gerenciar recursos.

Quando o OpenClaude estiver ativo no seu terminal, você pode digitar comandos iniciados por barra (/) para executar ações imediatas:

Comando Finalidade Exemplo de Uso
/provider Abre o assistente gráfico para alternar provedores e salvar perfis. /provider
/model Altera o modelo de LLM ativo sem sair da sessão. /model deepseek-chat
/init Analisa o projeto atual e cria diretrizes e regras no arquivo CLAUDE.md. /init
/compact Comprime o histórico da conversa para liberar a janela de contexto e poupar tokens. /compact
/cost Exibe a quantidade de tokens consumidos e o custo estimado da sessão atual. /cost
/doctor Faz um diagnóstico completo das ferramentas de sistema (Node, Git, Ripgrep, etc). /doctor
/clear Limpa o histórico de memória e inicia uma conversa do zero. /clear
/mcp Gerencia servidores MCP (Model Context Protocol) conectados ao agente. /mcp
/review Apresenta um diff detalhado de todas as alterações feitas no código antes de commitar. /review
/help Mostra a lista completa de comandos, atalhos de teclado e parâmetros. /help
Modo Não-Interativo (Prompt Direto): Você também pode rodar comandos diretamente do terminal sem entrar no chat com o parâmetro -p:
openclaude -p "Crie um endpoint Express em server.js com rota /health e teste"
Passo 06

Solução de Problemas no Windows

Respostas rápidas para os erros mais comuns enfrentados durante a instalação e execução.

Causa: A pasta global do npm não está registrada na variável de ambiente PATH do Windows.

Solução: Execute no PowerShell:

$npm = npm config get prefix; [Environment]::SetEnvironmentVariable("Path", "$([Environment]::GetEnvironmentVariable('Path','User'));$npm", "User")

Depois feche todas as janelas do terminal e abra novamente.

Causa: Política de segurança padrão do PowerShell bloqueando a execução de scripts .ps1.

Solução: Execute o comando para liberar scripts locais assinados para o seu usuário:

Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned -Force

Causa: Chave de API expirada, com espaço extra ou digitada incorretamente.

Solução: Verifique se a variável está com o valor correto digitando $env:OPENAI_API_KEY no PowerShell. Certifique-se de que a chave começa com sk-or-v1-.

Causa: O OpenClaude requer Node v22+ devido ao uso de APIs nativas recentes.

Solução: Atualize imediatamente usando o winget:

winget install OpenJS.NodeJS.LTS

Causa: O OpenClaude necessita do executável rg no PATH para varredura de código.

Solução: Instale o Ripgrep pelo winget:

winget install BurntSushi.ripgrep.MSVC
